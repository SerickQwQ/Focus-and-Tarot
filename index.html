💾 关于数据保存 About your data ▾

本站数据全部保存在你的浏览器本地（localStorage），没有服务器，也不会上传到任何地方。

✅ 这些操作不会清空数据

  • 刷新页面，关闭后再打开同一地址
  • 站内切换页面、切换语言、开关静音
  • 删除单条待办（只影响那一条）

⚠️ 这些操作会清空待办和专注记录

  • 浏览器「清除浏览数据」时勾选了网站数据 / Cookie
  • F12 开发者工具里删除本页的 Local Storage
  • 无痕 / 隐私模式，关闭窗口后数据即丢弃

⚠️ 数据还在，但看不到

  • 换浏览器或换设备（各存各的，不同步）
  • 换访问地址：本地文件、localhost、GitHub Pages 域名互相隔离，看起来像数据没了，其实各自还在原来的地址
  • 仓库改名导致 GitHub Pages 地址变化，也会被视为新地址

💡 重要数据建议定期手动备份；用同一个浏览器、同一个地址访问，数据才是连续的。

All data is stored locally in your browser (localStorage). No server, no uploads.

✅ These won't erase your data

  • Refreshing, or closing and reopening the same URL
  • Switching pages, language or sound on this site
  • Deleting a single todo (only removes that one)

⚠️ These will erase your todos and focus records

  • Browser "Clear browsing data" with site data / cookies checked
  • Deleting this site's Local Storage via DevTools (F12)
  • Using incognito mode — data is dropped when the window closes

⚠️ Data still exists but you can't see it

  • Switching to another browser or device (each keeps its own copy)
  • Switching URL: file://, localhost, and the GitHub Pages domain are separate origins — it looks like data vanished, but each origin keeps its own copy
  • Renaming the repo changes the Pages URL, which is also treated as a new origin

💡 Back up important data regularly. Use the same browser and same URL for continuity.
